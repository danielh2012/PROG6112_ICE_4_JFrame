# PROG5121 ICE task 2 GUI Calculator

This is a basic Calculator that has a functional GUI created using java swing's JFrame system it can do basic arithmetic operations like addition, subtraction, Multiply and Divide it also has checks in place to ensure the application doesn't crash without cause like dividing by 0.

![Alt text](./Images/Final_Product_2.png)

# Installation/Usage

This project made use of Apache Netbeans' GUI designer as such it will likely require Apache Netbeans to compile and run

Simply download the project and open the project in Apache Netbeans.
